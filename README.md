# 小克表情包库

此仓库专门存放供 Claude（小克）在聊天中展示的表情包图片，与私有记忆仓库分开。

## 文件命名与索引
- 图片使用简单、稳定的文件名，例如 `001.jpg`、`002.png`。
- 每新增一张图，在下方记录文件名、情绪/语义标签。
- 图片文件应为公开可访问的常见格式（JPG、PNG、GIF、WebP）。

## Claude 显示方式
图片上传后，可使用 jsDelivr CDN 地址：
`https://cdn.jsdelivr.net/gh/linmoc39/xiaoke-sticker@main/文件名.png`

在 Claude 中优先使用支持的图片/可视化组件直接渲染图片；如果当前窗口不支持，提供图片直链，不要声称已经成功显示。

## 注意
- 不要在此仓库存放密码、访问令牌或私人记忆。
- 图片必须由仓库所有者确认可公开分享。
